# Human Verification Shield (NeuroPulse Platform)
Production-grade multimodal deepfake detection engine protecting video calls and media against synthetic manipulation.

## Features:
- 🎙️ **Wav2Vec 2.0 Audio Countermeasure:** Detects voice cloning and TTS synthesis.
- 👁️ **EfficientNet-V2 Dual-Stream CNN:** Detects facial manipulation, GAN frequency grids, and spatial blending seams.
- 💓 **NeuroPulse Involuntary Biometrics:** Tracks eye aspect ratio (EAR) blink curves, Duchenne smile harmony, and rPPG subcutaneous blood volume pulse.
- 🌐 **Web Dashboard & REST API:** Real-time web testing, file analysis, and browser extension support.
